CAFEÍNA

CAFEÍNA é um painel web conectado a um backend Node.js. O servidor oferece API de status, integração com inteligência artificial, upload de arquivos em partes e download dos arquivos gerados.

No plano gratuito atual do Render, os arquivos são armazenados localmente. Isso significa que eles podem desaparecer caso a instância do servidor seja recriada.
